## ① 收口理由

1. 刀⑥主手段是 **运行时 BF16 面板 pack**；微基准显示相对⑤核更慢 → 主假设证伪，吞吐门 ≥2× **未达成**。
2. Agent 解释与机制一致：⑤ 的 strided 多行核已近顺序读带宽，pack 变成 **二次拷贝**，不增加有用字节/秒。
3. 既有降级条款已预留「优先 CORRECT、注明未过 2×」——收口是执行条款，不是改口。
4. 软件预取已在⑤a，不能把⑥粉饰成「预取成功刀」。

**收口记账（须写进合入文档/PR）**

- 吞吐门：未过（无合格 S1 墙钟 ≤42.9s 证据；微基准方向为负）
- pack：默认关；仅实验阀
- exact：合入后 default 路径须 S1 CORRECT PASS（硬）
